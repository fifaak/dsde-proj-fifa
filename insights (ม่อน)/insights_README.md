### 3.3 สาเหตุ (พร้อมหลักฐาน)
1. **ภาพความละเอียดต่ำ** (352×288) 39% ของกรอบฝ่าฝืนเล็กกว่า 800 px (ราว 28×28) นับล้อไม่ได้ กระบะ รถตู้ และตู้ทึบ 4 ล้อจึงดูเหมือนรถบรรทุก ตรงกับที่ README ระบุว่าแยก 6/10 ล้อไม่ได้
2. **ตัวจำแนกมั่นใจเกินจริง** กรอบที่ผิดได้ p 0.71–1.00 และ p เฉลี่ยของรถที่ YOLO เรียกว่า `bus`/`car`/`truck` ต่างกันนิดเดียว (0.87 / 0.83 / 0.88)
3. **ไม่ใช้ความมั่นใจของ YOLO ประกอบ** ของข้างทางในภาพ cam219_20260825_1906 YOLO มั่นใจแค่ 0.17 แต่ตัวจำแนกให้ p = 1.00 · ใน 10 กรอบที่ผิดที่ตรวจ มี 9 กรอบที่ YOLO ต่ำกว่า 0.5 (แต่รถจริงบางคันก็ต่ำเหมือนกัน เช่น 0.19)
4. **กรอบซ้อน** วัตถุเดียวถูกกรอบทั้งเป็น `truck` และ `bus` (เห็นใน cam11_20260825_0655, cam11_20260828_1600, cam11_20260831_0810) ทั้งชุดซ้อน 338 รายการ (10.3%) กล้อง 11 ซ้อน 15.3%
5. **รถบัสกับรถหนักสับสนสองทิศ** รถโม่ปูนสีเหลืองถูกปัดเป็นรถบัส (p_heavy 0.59 ตกเส้นตัด 0.6 ไปแค่ 0.01) ขณะที่รถที่ YOLO เรียกว่า `bus` อีก 759 รายการถูกนับเป็นรถหนัก
6. **ผลไม่นิ่ง** ของข้างทางชิ้นเดียวกันเป็น `other` (p_heavy 0.40) ในเฟรม 18:56 แล้วเป็นรถหนักในเฟรม 19:06 ตัวกรองวัตถุอยู่กับที่ยังไม่ดักเคสนี้
7. **ฉากยากและข้อมูลฝึกน้อย** ภาพส่วนใหญ่เป็นช่วงเร่งด่วนที่รถติดและบังกัน ตัวจำแนกฝึกจากกรอบที่ติดป้ายมือ 450 กรอบ (รถหนัก 141) และชุดทดสอบ 90 ป้าย (รถหนัก 29) ตัวเลข precision จึงมีช่วงไม่แน่นอนกว้าง

5. วงกลมแบ่งสี "ชัวร์" กับ "สงสัย" แทนสีเดียว เพื่อสื่อว่ามีความไม่แน่นอน
